# 转换流程与验收

## 结构与翻译

中间表示记录输入 SHA-256、页尺寸、CropBox/MediaBox、文本块与 span 的字体/粗细/方向/坐标、图片摘要与坐标、绘图、阅读顺序、表格及公式区域。解析出的块不一定是完整段落：跨块段落可共同翻译，但保留子 ID 与各区域映射；不要机械把相交块合并，尤其是公式和双栏文本。

先人工检查解析结果：首页标题、作者、摘要、第一幅图；方法页；密集公式页；表格页；附录。修正误分类并记录原因。参考文献中的题名也属于自然语言，姓名、出版信息和标识符保留。算法名称不翻改。

在当前助手中直接完成翻译即可，不默认要求另购 API。大论文分批缓存；每批携带全文摘要、当前章节上下文、术语表和已确定术语。用外部翻译接口时只使用已有获准配置，不捆绑密钥、不自行寻找凭证。翻译应带原 ID 和 source hash，检验重复 ID、缺失条目及数学占位符。

## 渲染

在原页面副本上替换。先试排，确认成功再提交删除/插入，溢出则局部调整或保留源对象并报审校。标题可使用少量邻接留白，调整前检查所有文字/图像/绘图/公式障碍物。图注按原位置自动换行；字号缩小后检查与图形距离和空白是否协调。

Windows 本次使用宋体正文、微软雅黑真粗体标题、Times/Cambria 补充拉丁与数学字体；其他系统使用实际可用且允许嵌入的中文字体并核验符号。不要打包系统字体。脚本的 pt 单位必须与原页尺寸一致；小页面不得机械套用 Letter 页字号。

图内文字必须建立独立标签记录：页、框、来源 native/OCR/outlined、原文、译文、背景与审核状态。OCR 结果须对照图像核实，不能修改实验数值、颜色编码、箭头或坐标刻度。复杂背景先保留、列待审校。扫描整页论文需要 OCR+区域精修，不能以整页白底重排冒充镜像。

## 检查

- 页数及逐页宽高、旋转、裁切框；图片摘要、实例数量及位置（不能只比 xref）。
- 公式区域独立截图比对，特别是分式横线、上下标、变量和编号；公式不得被文字删除范围碰到。
- 试排返回值及实际字号，不能把缩到不可读视为成功；检查缺失字形和重叠。正文小于约 8 pt、图注小于 8 pt 应主动审查，不自动作为达标。
- 同分辨率截图比较替换框之外变化，遮罩取实际源删除区与目标写入区并集，抗锯齿容差要记录。通过只证明外部稳定，不证明框内正确。
- 译文覆盖清单；独立检查生成 PDF 中剩余英语（姓名/模型/缩写允许），再检查位图/轮廓图表。未做 OCR 不得声称图内文字全部翻译。
- 全页缩略图检查布局，再放大首两页、长侧边图注、方法标题、公式密集页及所有异常页。保存完整截图，报告已实际目视检查页。

## 阅读器（用户需要时）

两侧使用同一 PDF.js 渲染器，按同一页号对齐，支持同步滚动、缩放、单/双页、原文/译文切换、下载和审校结果。可使用 assets/nv-cot/viewer.js，配合 package_viewer.py 的 HTML 壳；复制到任务目录后将标题、文件名与路径参数化，页数从 PDF 读取。PDF.js 及许可从可用运行时取得，不依赖用户连网。核验下载字节与交付 PDF 一致，左右均为实际 PDF canvas；浏览器未验证时如实注明。
